## タスク
## 概要

ダッシュボード (dashboard.tsx) の操作性を改善する。フォーカスベースのナビゲーション、全エリアのスクロール対応、カーソル表示の改善を行う。

## 要件

### 1. フォーカスシステムの導入

状態を「グローバル（フォーカスなし）」と「エリアフォーカス中」の2モードに分ける。

| 状態 | 有効キー |
|---|---|
| グローバル（初期/ESC後） | T J L A r q Q |
| Tasks フォーカス | ↑/↓ スクロール、ESC で戻る |
| Journal フォーカス | ↑/↓ スクロール、ESC で戻る |
| Log フォーカス | ↑/↓ g/G スクロール、ESC で戻る |
| Artifacts フォーカス | ↑/↓ Enter s f、ESC で戻る |

- `T` → 常時表示の Tasks エリアにフォーカス
- `J` / `L` / `A` → 下部タブを切り替え + そのエリアにフォーカス
- `ESC` → フォーカス解除（グローバル状態に戻る）
- グローバルキー（r, q, Q）はグローバルフォーカス時のみ有効

### 2. 各エリアのスクロール対応

- **Tasks**: 既存の ↑/↓ スクロールがバグで動かない問題を修正。taskCursor が TASK_VISIBLE_LINES の境界で止まる。daemon.taskList の切り詰めや境界条件を調査
- **Journal**: スクロール未実装。journalScrollOffset を追加し、Log タブと同様のスクロール機構を実装
- **Log**: 対応済み（j/k → ↑/↓ に変更）
- **Artifacts**: 既存の j/k カーソル移動を ↑/↓ に変更
- 表示エリア高さは現行通り（TASK_VISIBLE_LINES=5, LOG_VISIBLE_LINES=30）

### 3. Tasks カーソル表示の改善

- カーソルはフォーカス時のみ表示（現行通り）
- 先頭の `_ ` ではなく、選択行全体に underline スタイルを適用
- rezi-ui は underline を完全サポート済み（underlineStyle, underlineColor も利用可能）
- `{ underline: true }` を選択行の全テキスト要素に適用する

### 4. フッター（ステータスバー）のキーガイド

フォーカス状態に応じて該当キーのみ表示:
- グローバル: T tasks / J journal / L log / A artifacts / r reload / q quit / Q full quit
- Tasks: ↑/↓ scroll / ESC back
- Journal: ↑/↓ scroll / ESC back
- Log: ↑/↓ scroll / g top / G bottom / ESC back
- Artifacts: ↑/↓ select / Enter open / s sort / f filter / ESC back

## 対象ファイル

- skills/cmux-team/manager/dashboard.tsx

## 技術メモ

- AppState に `focusedArea: 'global' | 'tasks' | 'journal' | 'log' | 'artifacts'` を追加
- 既存の activeTab は focusedArea と連動（J/L/A 押下時に両方更新）
- rezi-ui の TextStyle: `{ underline: true, underlineStyle?: 'straight' | 'double' | 'curly' | 'dotted' | 'dashed', underlineColor?: Rgb24 }`
- 既存の j/k キーバインドは ↑/↓ に統一（フォーカスエリアに応じて動作を分岐）
